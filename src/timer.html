流程预设 存储 · 复用 · 分享

预设只保存环节流程（名称 / 时长 / 类型 / 初始发言方），不保存队伍信息，同名预设会被覆盖。「导出全部预设」生成 JSON 文件，可在其他电脑的计时器里通过「上传预设文件」导入。「复制预设链接」会把当前流程编码为短链接（?preset=…），对方打开链接即自动导入；若链接未携带编码，则按本地预设正常加载。

环节设置

时长支持 m:ss 或秒数（如 3:30 或 210）；「双方计时」可切换发言方，「单方计时」为单个倒计时。配置会自动保存在本机浏览器中。
